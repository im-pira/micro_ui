# micro-ui

A playful collection of tiny UI experiments, components, and interactions.

Built to explore small interface ideas, animations, and design details — from docks and calendars to toggles, inputs, and more.

## What's inside

* UI components
* Micro-interactions
* Animation experiments
* Small design explorations
* Reusable interface ideas

## Goal

To build simple, polished UI pieces and experiment with how small details can make interfaces feel better.
